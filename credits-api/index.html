Peanut Credits API

Simple documentation of all available endpoints

Base URL: http://localhost:3000/api/credits
GET /api/credits

Returns the current credit balance and won milestones for the player.

Headers

X-Player-Id: <uuid>   (optional – a new player is created if missing)

Example Response

{
  "credits": 3,
  "milestonesWon": [16, 32, 64],
  "canPlay": true
}
POST /api/credits/use

Spends 1 credit to start a new round. Returns 402 if the player has no credits.

Headers

X-Player-Id: <uuid>
Content-Type: application/json

Example Response (success)

{
  "success": true,
  "credits": 2
}

Example Response (no credits)

{
  "success": false,
  "message": "Insufficient credits"
}
POST /api/credits/redeem

Redeems a purchase code and adds the corresponding credits.

Headers

X-Player-Id: <uuid>
Content-Type: application/json

Request Body

{
  "code": "SMALL-1234"
}

Example Response (success)

{
  "success": true,
  "amount": 1,
  "credits": 4,
  "message": "Added 1 credit(s). Enjoy!"
}
POST /api/credits/milestones

Records a tile milestone. Awards bonus credits only the first time the value is reached.

Request Body

{
  "value": 256
}

Example Response (first time)

{
  "success": true,
  "firstTime": true,
  "bonus": 3,
  "credits": 7,
  "message": "256 tile reached! +3 credits"
}
POST /api/credits/score-bonus

Awards end-of-round score bonus (capped). Call this once when a round ends.

Request Body

{
  "score": 1840
}

Example Response

{
  "success": true,
  "bonus": 6,
  "credits": 13
}
Important: Every request should include the header X-Player-Id. If it is missing, the API automatically creates a new player and returns the new ID in the response header X-Player-Id. Store this ID in localStorage and send it on all future requests.
